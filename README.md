# CRS Digital · Web

Web de CRS Digital (Logroño): diseño web, redes sociales, automatización y mantenimiento.

- `index.html`, `servicios.html`, `proyectos.html`, `nosotros.html` — las páginas.
- `aviso-legal.html`, `privacidad.html`, `cookies.html`, `terminos.html`, `borrar-datos.html` — textos legales.
- `js/site.js` — animaciones, navegación entre páginas, aviso de cookies (Google Analytics y Píxel de Meta solo con permiso) y formulario de contacto.
- `assets/` — imágenes; `fonts/` — tipografías (licencia SIL OFL 1.1, ver `fonts/LICENCIAS.txt`).
